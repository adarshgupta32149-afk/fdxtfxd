Your data & backups

Everything you type is saved on this computer only, inside this browser — no internet, no account.

• Click ⬇ Backup (top right) regularly to save a .json file somewhere safe (USB drive, Documents folder).
• Use ⬆ Restore to load that file back, or to move your data to another computer.
• Keep the stock-tracker.html file itself anywhere; double-click to open it any time.

Important: clearing your browser data, or using private/incognito mode, can erase everything — so keep backups.
